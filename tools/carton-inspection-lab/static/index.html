EASY REFERENCE

Carton model settings guide

What each control does and when you should change it.

Best starting pointConfidence 0.27 · IoU 0.70 · Resolution 960

Always test on the same verified images. Change only one setting at a time.

00

Model library

Select which local YOLO checkpoint performs the prediction. Drop a trusted .pt file to validate and add it without restarting the app.

Only upload checkpoints you created or obtained from a trusted source.
01

Verified carton count

The correct count entered by a person. It does not affect prediction—it only tells you whether the model was exact, undercounted or overcounted.

Example: If there are really 62 cartons, enter 62.
02

Confidence threshold

The minimum certainty required to keep a carton. Lower values find more cartons but can add false detections. Higher values remove weak detections but can miss cartons.

Undercounting? Try slightly lower. Overcounting? Try slightly higher.
03

NMS IoU

Controls when overlapping predictions are treated as duplicates. It mostly affects two detections that cover the same carton.

Keep 0.70 initially. Change it only after visually confirming duplicate boxes.
04

Inference resolution

The image size examined by the model. 640 is fastest, 960 is the balanced default, and 1280 can help with small or distant cartons but takes longer.

Use 960 for normal tests. Use 1280 only when carton faces are small.
05

Polygon masks

Shows the exact segmented carton shape. This is the best view for checking whether the model understood each carton boundary.

This display switch does not rerun or change the prediction.
06

Bounding boxes

Draws a rectangle around every detected carton. Boxes are useful for quickly finding missing or duplicated detections.

Turn masks off and boxes on for a cleaner error review.
07

Carton numbers

Numbers detections from top to bottom and left to right. The largest number equals the total detected-carton count.

Use numbers when manually auditing the result.
08

Confidence labels

Shows the model certainty for each individual carton. Low-confidence cartons deserve closer visual checking.

Enable this when investigating why a carton appears or disappears.
09

Mask opacity

Changes how strongly the colored masks cover the photograph. It affects appearance only—not the count or accuracy.

Use 20–30% to keep carton printing visible underneath.
10

Compare verification

Open Compare and verification activates automatically. Click a carton on either photo; the same numbered green tick appears on both images.

Click the same tick to remove it. Undo, Clear and Export review are also available.

Safe tuning order

1Start with 0.27 / 0.70 / 960→2Check missing and extra cartons→3Adjust confidence slightly→4Try 1280 only for small cartons
