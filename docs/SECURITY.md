# Security Policy - Logistics Vision AI

We treat code security and data protection as a priority. This document defines how vulnerabilities are managed and resolved.

---

## 1. Supported Versions
We actively support security patch deployments on the active release branch:
*   **Version 1.x**: Supported for security vulnerabilities.
*   **Versions < 1.0**: Deprecated. No patches will be released.

---

## 2. Reporting a Vulnerability
If you discover a vulnerability, please report it securely:
1.  **Do Not File Public Issues**: Avoid disclosing vulnerabilities publicly.
2.  **Submit Secure Report**: Email details to `security@logisticsvision.ai`.
3.  **Required Information**:
    - Detailed explanation of the vulnerability.
    - Step-by-step instructions to reproduce the issue.
    - Potential impact assessment.
4.  **Acknowledgment**: We will acknowledge receipt of your report within 48 hours and outline expected remediation windows.
